# biomed-quizzes

Practice quizzes for biomedical engineering courses: biomedical sensors and instrumentation, biosignal circuits and diagnostic imaging.

**Open the shelf: <https://hung-nduc.github.io/biomed-quizzes/>**

Each quiz is one HTML page that runs in the browser, offline too. Practice quizzes show whether an answer is right as you go. The two practice exams grade when you submit, with a time limit and a pass mark. Nothing is sent anywhere: your answers stay in your browser.

To keep a quiz offline, open it and save the page (Ctrl+S). It works from your disk with no internet connection.

## Where the quizzes come from

They are written for self-study, adapted from course materials with the help of AI. They are not real past exams, and they may contain mistakes. If you find one, please open an issue.

## How this repository is made

The pages are built with [fullmark](https://github.com/hung-nduc/fullmark) from Markdown sources, which sit in each quiz's folder next to its `index.html`. The quiz folders, `index.html` and the manifest, `fullmark-shelf.json`, are written by `quiz library publish`, so edits to them here are replaced at the next publish. This README is not touched.
